## v0.1.0 — 첫 공개 (2026-10-15)

PDF 합치기·병합과 압축·용량 줄이기를 **파일을 올리지 않고** 내 PC에서 하는 Windows 프로그램. 설치 없이 exe 하나.

**합치기** — 끌어다 놓은 순서대로 하나로. 파일마다 넣을 쪽 범위(`1-10, 15, 20-`), 각 파일의 책갈피(목차)는 파일 이름 아래에 묶어 유지, 링크·주석 유지. 결과 `첫파일명_merged.pdf`.

**용량 줄이기** — 이미지만 다시 압축(JPEG 보통·작게·최소, 해상도 상한 300·200·150 dpi). 글자 검색·책갈피·링크·쪽 크기는 그대로. 실행 전 예상 크기 표시, 결과가 원본보다 작지 않으면 만들지 않음. 결과 `원본명_small.pdf`.

공통: 원본 무수정, 같은 이름이 있으면 번호, 암호 PDF는 안내 후 건너뜀, 진행률·중단, 한국어·English·中文·日本語, 명령줄 지원(`--merge`, `--shrink`).

**새 버전 확인**: 실행할 때 도구 이름(`pdfmerge`)과 버전만 책갈피 서버(chaekgalpi.co.kr)에 보내 새 버전이 있으면 창 아래에 한 줄로 알립니다. 파일은 보내지 않고, 하루 한 번, 설정에서 끌 수 있습니다.

exe에는 AGPL-3.0인 PyMuPDF가 들어 있어 exe 전체가 AGPL-3.0입니다. 소스는 이 저장소, 구성 요소는 THIRD_PARTY_LICENSES.txt. 서명하지 않은 exe라 SmartScreen 경고가 뜨면 「추가 정보 → 실행」.

**v0.1.0 — first release.** Merge PDFs (order, per-file page ranges, bookmarks kept per file) and compress them (images re-encoded; text, bookmarks and links untouched) on your own PC - nothing is uploaded. One exe, no install, originals never modified. Korean, English, Chinese, Japanese UI and a command line. On start it only sends the tool name and version to chaekgalpi.co.kr to check for a newer version (once a day, can be turned off). The exe bundles PyMuPDF (AGPL-3.0); source is this repository.
