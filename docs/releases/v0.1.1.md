## v0.1.1 — 「의견 보내기」 (2026-10-26)

창 위쪽 「새 버전 확인」 옆에 **의견 보내기** 링크를 넣었습니다. 누르면 브라우저에서 책갈피 툴 페이지의 의견 칸(https://chaekgalpi.co.kr/tools/pdfmerge#feedback, 영어·일본어·중국어 화면은 영어 페이지)이 열리고, 로그인 없이 안 되는 것·불편한 것·바라는 기능을 보낼 수 있습니다. 프로그램은 주소를 브라우저에 넘길 뿐 직접 보내는 것은 없습니다. 브라우저가 열리지 않으면 주소를 안내 창과 기록 칸에 보여 줍니다. GitHub Issues 도 그대로 받습니다.

합치기·용량 줄이기 동작은 v0.1.0 과 같습니다.

---

**v0.1.1 — Send feedback.** A **Send feedback** link next to "Check for updates" opens the feedback form on the tool's page (https://chaekgalpi.co.kr/en/tools/pdfmerge#feedback) in your browser - no sign-in needed. The program only hands the address to the browser and sends nothing itself; if no browser opens, the address is shown in a message and in the log. GitHub Issues are welcome too. Merging and compressing are unchanged from v0.1.0.
